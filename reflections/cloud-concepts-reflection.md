Reflection on Cloud Computing Concepts

Cloud computing has become an important part of my daily life, even when I do not immediately realize that I am using it. Three cloud-based applications that I regularly use are Google Drive, Canva, and Messenger. Google Drive allows me to store, organize, and access documents through the internet. Canva helps me create presentations, posters, and other visual materials online. Messenger allows me to communicate with classmates, friends, and family using an internet-based platform.

These applications can be classified under the Software as a Service or SaaS model because users can access complete software applications through the internet without installing or managing the underlying servers and infrastructure. Google Drive, Canva, and Messenger are also commonly delivered through public cloud environments because their services are made available to many users through infrastructure managed by the service providers. However, some organizations may use private or hybrid cloud systems when they need greater control, security, or integration with their own systems.

Git and GitHub are also useful when working on cloud computing projects. Git provides version control, which records the changes made to files over time. This makes it easier to identify who made a change, restore an earlier version, and avoid losing important work. GitHub provides an online platform where team members can store files, share updates, and collaborate on the same project.

Version control is especially important in cloud infrastructure because configuration files may affect servers, applications, and other resources. A small incorrect change can cause errors or service interruptions. By using GitHub, teams can review modifications before applying them, track project history, and coordinate their work. Through this activity, I learned that cloud computing and version control work together to make digital projects more organized, accessible, collaborative, and reliable.
